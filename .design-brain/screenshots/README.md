# Screenshots

This folder stores screenshots used as visual evidence for Codex Design Brain reviews.

Name screenshots clearly so they are easy to connect to a task, viewport, and state. Avoid huge unnecessary files when a cropped or compressed screenshot is enough for review.

Examples:

- `homepage-desktop.png`
- `homepage-mobile.png`
- `pricing-section-before.png`
- `pricing-section-after.png`
