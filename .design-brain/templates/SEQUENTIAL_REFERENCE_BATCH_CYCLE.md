## Hard-Gate Reminder

- This cycle must follow `.design-brain/BATCH_TEMPLATE_HARD_GATES.md`.
- The cycle order is product family classification -> reference selection -> cognition extraction -> structure fingerprint -> visual-language fingerprint -> output contract -> build -> visual inspection when possible -> quality gate -> similarity diagnosis -> pattern lock -> scaffold disposal receipt -> fresh next cycle.
- The output must be closer to this cycle's selected reference insight than to any accepted previous template.
- If similarity appears later, diagnose root cause before revising: structure, composition, effects, visual-language weakness, color only, or copy/naming only.
- Structure similarity requires rebuild. Color-only similarity requires recolor. Copy-only similarity requires rewrite.
- Effect/gradient/surface-depth decisions are automatic. Do not wait for the user to mention them.
- Clean but flat, under-art-directed, or invisible-effect output fails the cycle unless deliberate restraint is evidenced.
- If this cycle uses a Figma reference/link/source, complete the professional Figma template reading order and a Figma reference schema receipt before structure planning.
- Unknown Figma product standard must be resolved through evidence, corpus/category lookup, or one targeted question; never through minimalist fallback.
