# Reference Insights

This folder stores generated reference insight entries.

Reference insight files are project/product learning artifacts. They should capture what Codex learned from a reference without copying the reference directly.

Use these files to record:

- Design intent
- Audience and mood
- Hierarchy and section logic
- Marketplace value
- Reusable lessons
- Do-not-copy notes
- Future reinterpretation directions

The files in this folder are not reflection logs and are not stable core memory. Useful repeated lessons can later be converted into reflection entries or promotion proposals only through the controlled workflows.

Generated reference insight files are not copied into new projects by default by the installer.
