## Rules

- Record patterns the user rejects as generic, messy, copied, cheap, uneditable, or weak.

## 2026-05-26 - Reduced Structure As Default

- Rejected pattern: choosing fewer website sections/pages because the design mood feels restrained.
- Reason: website template structure must depend on template purpose, target buyer, marketplace category, and end-user journey.
- Reuse rule: clean visual style is allowed, but missing required sections, pages, screens, states, or proof blocks is a structure failure.
