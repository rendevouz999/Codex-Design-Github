# Pilot Reports

Pilot reports store real project trial runs for Codex Design Brain. They help plan the first design task in a project, record installation readiness, identify missing workflow files, and outline review, visual review, and reflection commands.

Pilot reports are not reflection logs. They may include project-specific context, paths, URLs, screenshots, and assumptions, so they should not always be copied to other projects.

Useful lessons discovered during a pilot should later be captured in `.design-brain/REFLECTION_LOG.md` with `scripts/design_brain_reflect.py`.
