# Template Orchestrations

This folder stores generated orchestration reports for sellable template products.

An orchestration report is a planning artifact. It defines the template product, buyer, niche, style strategy, section structure, editability requirements, preview direction, quality gate, and next review commands.

These reports are not reflection logs. If a user gives reusable feedback after a template task, capture the lesson with `scripts/design_brain_reflect.py`.

Orchestration reports may contain project-specific or product-specific context. Do not blindly copy generated reports across unrelated projects.

Generated reports are not copied into new projects by default by the installer.
