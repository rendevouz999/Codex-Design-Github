# Proposed Rules

This folder stores lessons that are not active rules yet.

By default, continuous learning produces proposed rule changes here, not immediate global workflow changes. A proposed rule can be promoted only when the scope is clear and at least one promotion condition is met:

- The user explicitly asks to update Brain Design rules.
- Repeated user feedback supports the same lesson.
- Multiple evidence sources support the lesson.
- The rule fixes a known failure mode with low overgeneralization risk.

Never generalize one niche-specific lesson into a global rule without review.
