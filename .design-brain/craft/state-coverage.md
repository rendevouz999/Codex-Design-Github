# State Coverage Craft

- Stateful UI must include default, hover, active, focus, disabled, loading, empty, error, and success where relevant.
- Dashboards require filter, table row, chart, and detail-panel states.
- Forms require valid, invalid, focused, helper, disabled, submitting, and success states.
- Mobile flows require screen-to-screen continuity and clear navigation states.
- UI kits must document variants and states, not only component shells.
- If a state is omitted, the plan must say why it is out of scope.
