# Responsive Behavior Craft

- Plan mobile, tablet, desktop, and wide behavior before finalizing layout.
- Do not merely shrink desktop into mobile.
- Define reflow for nav, hero, grids, tables, media, CTAs, and forms.
- Prevent text overflow through sensible width constraints and wrapping.
- Product previews must remain inspectable on both desktop and mobile frames.
- Dashboards need compact density and table alternatives on small screens.
- Marketplace previews should show enough responsive evidence to build buyer trust.
