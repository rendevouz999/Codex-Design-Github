# Marketplace Originality Craft

- A template product must show category, buyer use case, editability, and completeness clearly.
- Reference mood is allowed; copied order, grouping, motif, title placement, and preview staging are not.
- Batch templates need different archetypes, first structural moves, hierarchy anchors, and rhythms.
- Preview covers must reveal actual product quality, not hide it behind dramatic mockups.
- Naming should avoid recycled metaphors from prior builds or references.
- If similarity risk is above threshold, redesign structure before visual polish.
