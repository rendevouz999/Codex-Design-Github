# Typography Craft

- Define roles before picking fonts: display, heading, body, caption, label, mono.
- Use type scale to express hierarchy, not random weights.
- Keep body text readable and avoid viewport-width font scaling.
- Use tabular numerics for metrics, dashboards, pricing, and slide stats.
- Avoid decorative type if it does not improve meaning, category signal, or buyer trust.
- For compact interfaces, reduce size jumps and rely on weight, spacing, and grouping.
- For editorial/portfolio work, allow stronger display contrast but preserve body measure.
