# Section Layout Library

This catalog stores section-level layout patterns extracted from reference
templates.

Stable patterns live in each section folder under `patterns/`. Automated
extraction candidates live in `_incoming/` until the Hyper-Accuracy Gate passes.
Duplicate and near-duplicate evidence lives in `_incoming/_matches/` so the
catalog does not grow by repeated section grammar.

Use this catalog as a vocabulary of section logic, not as a page scaffold.
