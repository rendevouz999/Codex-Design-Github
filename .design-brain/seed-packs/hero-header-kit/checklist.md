# Hero Header Kit Checklist

## P0

- Product is labeled as hero/header kit or banner pack.
- Variant count is explicit.
- Desktop and mobile behavior is planned.
- Navigation, CTA, headline, and media/visual placeholder are editable.
- The kit does not pretend to include full website structure.

## P1

- Variants differ by real composition, not only color or image swap.
- Each hero supports a different buyer use case or content density.
- Marketplace preview shows variant breadth clearly.
