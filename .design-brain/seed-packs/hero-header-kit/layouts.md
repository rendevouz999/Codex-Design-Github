# Hero Header Kit Layouts

Use this seed pack only when the product is explicitly a hero/header/banner kit, not a full website template.

## Structure Count Standards

- 1-4 hero/header layout variants for narrow packs.
- 5-12 variants for broader marketplace header kits.
- Each variant should include desktop and mobile behavior.
- Include navigation state, CTA placement, media placeholder, and background/motif rules.

## Required Areas

- Brand/logo placeholder.
- Navigation structure.
- Primary headline.
- Supporting copy.
- Primary CTA and optional secondary CTA.
- Trust cue, metric, badge, or category label when relevant.
- Media, product, image, or illustration placeholder when the hero needs visual evidence.

## Scope Rule

Hero/header kits are valid products, but they must not be presented as complete website templates.
