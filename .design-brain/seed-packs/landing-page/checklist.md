# Landing Page Checklist

## P0
- First viewport states category, audience, and offer.
- One primary CTA is obvious.
- Responsive desktop/mobile logic exists.
- Structure count matches the landing-page goal: at least 8 sections for standard product/service template pages, or 10-14 for trust-heavy sales pages. Use 6-8 only when the brief explicitly asks for narrow campaign, squeeze, waitlist, or micro landing scope.
- The brief explicitly asks for landing, campaign, lead-generation, sales-page, squeeze-page, waitlist, or one-off conversion intent.
- Restrained visual mood does not justify missing proof, detail, objections, conversion closure, or footer trust.
- No repeated generic hero/features/pricing/FAQ/CTA skeleton without variation.
- If the task is a full website template, do not use the landing-page checklist as the whole structure.
- If the task says website template, SaaS website, ecommerce, portfolio, blog, docs, dashboard, marketplace/listing, education, event, travel, or service website without explicit landing-page language, reroute to the website-template taxonomy.

## P1
- Proof appears before deep feature explanation.
- Each section advances the decision.
- Design system covers nav, buttons, forms, cards, media, and footer.
