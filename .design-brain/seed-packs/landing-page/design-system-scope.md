# Landing Page Design System Scope

- Color, type, spacing, radius, shadow, grid, breakpoints.
- Header/nav, buttons, forms, cards, media frames, testimonials, pricing/offer, FAQ, footer.
- Desktop and mobile section behavior.
- Section-density rules for short, standard, and long-form landing pages.
- Proof, objection, and conversion modules must be designed as reusable blocks, not improvised one-off content.
