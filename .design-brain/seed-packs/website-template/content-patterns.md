# Website Template Content Patterns

## Purpose First

- Business/corporate: credibility, services, proof, process, case studies, team, contact.
- Agency/portfolio: visual work, capabilities, selected projects, process, testimonials, about, contact.
- Service/local business: trust, offer, service list, service details, location/contact, FAQ, booking or lead form.
- SaaS/technology: product value, use cases, feature depth, workflow, integrations, pricing, proof, demo CTA.
- Ecommerce: product discovery, category navigation, product proof, cart/checkout, account trust, shipping/returns/support.
- Dashboard/admin: operational tasks, KPI scanning, charts, tables, filters, forms, states, settings.
- Blog/editorial: content discovery, categories, featured posts, article detail, author trust, newsletter.
- Health/medical/wellness: provider trust, services, credentials, appointment CTA, testimonials, FAQ, contact/location.
- Travel/event: destination/event story, packages, schedule, gallery, booking, testimonials, FAQ.

## Homepage Flow Options

- Trust-first flow: hero, credentials, services, proof, process, testimonials, FAQ, CTA, footer.
- Product-first flow: hero, product preview, benefits, feature depth, use cases, pricing, FAQ, CTA, footer.
- Portfolio-first flow: hero, selected work, capabilities, process, case studies, testimonials, contact, footer.
- Ecommerce flow: hero/collection, categories, product grid, featured deal, brands, social proof, blog/newsletter, footer.
- Editorial flow: hero/featured story, categories, latest posts, popular posts, author/brand, newsletter, footer.

## Copy Rule

- Every section must answer a buyer or end-user question.
- Remove sections only when the product type does not need that question answered.
- Add sections when trust, comparison, proof, transaction, or support is required by the template purpose.
- Before building, write the buyer question answered by each planned section. If the plan has fewer questions than the product type normally requires, the structure is probably underbuilt.
- A clean page can use restrained copy, but it still needs enough content roles to support discovery, understanding, evaluation, and conversion.
