# Brain Design Compatibility

Design Craft v0.3.0 is a support layer for Brain Design.

When Brain Design context is present, Brain Design owns:

- route
- product family
- output mode
- design cognition
- simulation verdict
- layout originality status
- section structure
- post-build status
- final readiness

Design Craft may support:

- color refinement within Color Role Re-Mapping
- typography
- spacing
- component anatomy
- component states
- accessibility
- source handoff
- polish notes

Design Craft must block override attempts and return `BLOCKED_BY_BRAIN_DESIGN_CONTRACT`.
