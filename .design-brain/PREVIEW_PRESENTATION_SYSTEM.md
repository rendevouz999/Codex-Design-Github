# Preview Presentation System

Use this system to plan cover images, marketplace previews, section breakdowns, and overview layouts.

## Preview Goals

- Communicate template category instantly.
- Show the strongest visual moment first.
- Prove the template is complete and editable.
- Show enough detail for buyers to inspect quality.
- Make the product feel premium, modern, and ready to use.

## Recommended Preview Set

- Cover: strong first image with product name, category, and a hero composition.
- Full page preview: show the complete landing page or main screen.
- Section breakdown: display key sections as labeled slices or tiles.
- Responsive preview: desktop and mobile frames together.
- Component overview: show reusable components, states, or tokens.
- Style overview: color, typography, spacing, and UI details.
- Perspective mockup: optional, used only when readability remains strong.

## Cover Layout Patterns

- Hero canvas: one large template preview with concise product naming.
- Bento preview: multiple cropped sections in a clean grid.
- Perspective stack: overlapping angled screens with readable foreground.
- Dashboard wall: dense but organized cards and charts in a premium frame.
- Brand kit spread: logo, palette, typography, and collateral arranged as a system.

## Section Breakdown Rules

- Label sections by purpose, not decoration.
- Show different layout rhythms, not repeated cards only.
- Include CTA, proof, pricing, FAQ, and responsive examples when relevant.
- Keep preview captions short and useful.
- Avoid tiny unreadable screenshots.

## Perspective Mockup Rules

- Use perspective to increase desirability, not to hide flaws.
- Keep at least one flat, readable preview available.
- Avoid dark, blurry, or overly cropped mockups when buyers need to inspect UI.
- Use consistent shadows, depth, and background treatment.

## Marketplace Cover Checklist

- Product type is visible.
- Niche or buyer is clear.
- Main preview is readable.
- The composition has one dominant focal point.
- Supporting previews show breadth.
- The style feels intentional and differentiated.
- The cover does not rely on random decoration.
