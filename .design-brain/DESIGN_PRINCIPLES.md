# Design Principles

## Stable Principles

- Insight before output.
- Product purpose before visuals.
- Structure before decoration.
- Originality before similarity.
- Buyer clarity before aesthetic trend.
- Editability before visual gimmick.
- Marketplace readiness before one-off beauty.
- References teach intent, structure logic, hierarchy, mood, and market value.
- Template work must be reusable across client projects.
- Naming must be original and checked against the ledger.

## Reference Principles

- Never copy section order one-to-one.
- Never copy composition one-to-one.
- Never copy spacing rhythm one-to-one.
- Never copy image placement one-to-one.
- Never copy component grouping one-to-one.
- Do not merely change colors/text on a copied structure.
- Preserve the insight, not the appearance.

## Template Product Principles

- Every template needs a clear buyer and use case.
- Every template needs reusable sections or components.
- Every template should expose editable placeholders clearly.
- Marketplace previews should show the actual product value.
- Covers should sell the product without hiding weak structure.
- A template should feel designed for a category, not generated from a generic pattern.
