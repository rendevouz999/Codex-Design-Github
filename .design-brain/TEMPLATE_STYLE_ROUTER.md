# Template Style Router

Use this router to select only relevant TypeUI-derived style references for a template product. Never activate all TypeUI skills at once.

## Routing Workflow

1. Start with the template product type.
2. Identify the medium with `.design-brain/MEDIUM_PRODUCT_PLAYBOOKS.md`.
3. For Figma website templates, identify the product family with `.design-brain/FIGMA_WEBSITE_TEMPLATE_PRODUCT_TYPES.md`.
4. Identify niche, target buyer, and marketplace category.
5. Pick one core quality style.
6. Pick one layout or medium style.
7. Pick one optional niche or mood style.
8. Reject conflicting styles.
9. Convert selected skills into concrete design grammar before designing.
10. Use review and visual review reports before final delivery.

## Style Selection Rules

- Clean and Spacious can combine with nearly everything.
- Premium and Professional should guide quality, restraint, trust, and commercial polish.
- Perspective is mainly for cover, preview, mockup, and presentation systems unless the UI itself needs spatial depth.
- Storytelling should guide section order and conversion flow, not make every interface playful.
- Presentation Deck Pack should guide slide-role matrix, safe margins, footers, chart/table rules, and thumbnail readability.
- UI Kit System Pack should prioritize states, variants, token semantics, and usage documentation.
- Brand Kit Pack should prioritize identity application rules across touchpoints, not only attractive mockups.
- Dashboard should not dominate wedding, event, cafe, editorial, or soft lifestyle templates.
- Do not combine too many dominant moods in one product.

## Examples

- Wedding planning landing page: use Elegant Event Pack.
- SaaS product website: use SaaS Product Website Pack, not Landing Page Pack unless the brief explicitly says landing page.
- Ecommerce or listing/directory website: use Commerce Website Pack.
- Blog, magazine, publication, or CMS website: use Editorial Content Website Pack.
- Course, LMS, docs, help center, or knowledge-base website: use Knowledge Education Website Pack.
- Agency, studio, portfolio, resume, or case-study website: use Portfolio Studio Website Pack.
- Home repair booking template: use Service Business Pack.
- Freelancer hiring platform: combine Dashboard Product Pack and Service Business Pack.
- Editorial publishing template: use Editorial Publishing Pack.
- Marketplace preview cover: use Marketplace Preview Pack.
- PowerPoint proposal deck: use Presentation Deck Pack.
- Design system or UI kit: use UI Kit System Pack.
- Brand guideline template: use Brand Kit Pack.

## Output Requirement

Every style decision should explain:

- selected style pack
- selected skills
- why each skill was selected
- rejected or conflicting styles
- section structure implications
- medium/product-type implications
- preview and cover direction
- marketplace quality criteria
