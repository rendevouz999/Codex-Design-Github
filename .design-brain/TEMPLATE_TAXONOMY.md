# Template Taxonomy

Use this taxonomy to classify the template product before designing.

For Indonesian or mixed-language prompts, expand routing through `.design-brain/ROUTING_ALIASES_ID.json` before classification. Product-specific signals beat generic `template website` wording.

## Website And Landing Page Templates

- Landing page template: single-page marketing site with a focused conversion goal.
- Figma website template: editable website layout built in Figma, usually with multiple sections and responsive frames.
- Portfolio template: personal or agency showcase with work, services, process, testimonials, and contact.
- Ecommerce landing template: product-focused page with hero, product story, features, social proof, pricing, FAQ, and checkout CTA.
- Event or course template: campaign page for registration, agenda, speaker/teacher, proof, FAQ, and CTA.

Indonesian signal examples:

- `template website restoran`, `rumah makan`, `kafe`, `hotel`, `travel`, `venue`, or `pernikahan` -> event, venue, travel, hospitality, or booking website family.
- `template website keuangan`, `finansial`, `konsultan`, `akuntansi`, or `investasi` -> corporate/business/finance family.
- `template website sewa alat`, `rental`, `jasa`, `booking`, `klinik`, or `appointment` -> professional service or booking family.
- `template website perhiasan ecommerce`, `toko online`, `katalog produk`, `keranjang`, `fashion`, or `furnitur` -> ecommerce/storefront family.
- `template website properti`, `listing`, `direktori`, `job board`, or `lowongan` -> marketplace/listing/directory family.
- `template website kursus online`, `edukasi`, `pendidikan`, `kelas online`, `sekolah`, or `akademi` -> education/course/LMS family.
- `template website blog editorial`, `majalah`, `berita`, `publikasi`, or `media` -> editorial/blog/CMS family.
- `developer docs website`, `dokumentasi`, `pusat bantuan`, `knowledge base`, or `api docs` -> documentation/help center family.
- `admin dashboard web app`, `panel admin`, `analitik`, `pos`, `kasir`, `inventory`, or `laporan` -> dashboard/admin web app family.

## SaaS And Product Templates

- SaaS marketing template: hero, value proposition, product preview, features, integrations, pricing, testimonials, FAQ.
- Product launch template: bold announcement, features, demo preview, waitlist or buy CTA, social proof.
- Startup website template: investor/customer oriented pages with problem, solution, product, metrics, team, pricing, and CTA.

## Dashboard And Application Templates

- Dashboard template: metrics, charts, tables, filters, navigation, activity feeds, empty states, and settings.
- Admin template: app shell, sidebar, topbar, widgets, data tables, forms, authentication, settings, and user profile.
- Analytics template: KPI hierarchy, chart variety, comparison states, filters, exports, and insight panels.
- CRM/project template: lists, detail panels, pipeline states, collaboration, calendar, and task workflows.

## UI Kit And Design System Templates

- UI kit: reusable components, states, layouts, examples, and documentation blocks.
- Design system template: foundations, tokens, typography, color, spacing, components, variants, states, and usage rules.
- Component library template: focused collection of reusable primitives or product-specific components.

## Branding And Presentation Templates

- Branding kit template: logo usage, color, type, social layouts, stationery, packaging, and mockups.
- PowerPoint template: editable 16:9 presentation deck with slide masters, reusable layouts, slide-role matrix, chart/table rules, and closing/contact slides.
- Pitch deck template: narrative presentation for startup, product, investor, partnership, or sales storytelling with problem, solution, market, traction, team, and ask roles.
- Proposal deck template: business, project, service, or brand proposal deck with overview, scope, timeline, budget/rate, team, proof, and next-step roles.
- Portfolio deck template: slide-based creative or business portfolio with cover, introduction, work gallery, case study, testimonial, services, and contact roles.
- Marketplace preview layout: cover, hero preview, section breakdown, responsive previews, style overview, and feature/value panels.
- Template cover layout: high-impact first image that communicates category, mood, and product value.
- Perspective mockup overview: angled or staged previews that show multiple screens without losing readability.

## Web Deck And Animated Presentation Templates

- Web deck template: browser-rendered deck on a fixed 1920x1080 stage with slide roles, reveal order, runtime navigation, and a motion signature.
- HTML presentation template: single-file HTML deck that carries its own tokens, stage styling, and runtime without a build step.
- Animated presentation template: deck whose slide roles each receive a declared entrance and transition instead of one repeated effect.
- Browser presentation template: presenter-facing deck with keyboard, pointer, and wheel navigation, shareable slide deep links, progress chrome, and print-to-PDF output.
- Single-file deck: one portable HTML artifact that opens offline, with fonts as the only external request.
