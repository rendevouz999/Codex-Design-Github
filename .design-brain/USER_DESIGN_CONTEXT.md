# User Design Context

The user builds marketplace-ready template products and wants Codex to behave like an AI coding agent with designer perspective.

## Working Context

The user often works with:

- website landing page templates
- Figma website templates
- dashboard templates
- SaaS templates
- UI templates
- UI kits
- design system templates
- branding kit templates
- marketplace preview layouts
- mockup previews
- cover layouts
- design overview layouts
- editable design systems

## Reference Context

The user often works with visual references. References are used to avoid lost context, not to copy. The user wants insight, direction, and structural learning from references.

References should help Codex understand:

- intent
- mood
- hierarchy
- buyer expectation
- section logic
- preview strategy
- marketplace value

The user wants original template products, not copied layouts.

## Marketplace Quality Context

The user cares about Envato, Figma, and broader template marketplace quality. The work should feel editable, reusable, marketable, visually premium, and ready to present.

## Naming Context

The user wants template names to avoid repetition and recycled naming patterns. Names should be checked against prior names, niche patterns, suffix/prefix reuse, and metaphor repetition.
