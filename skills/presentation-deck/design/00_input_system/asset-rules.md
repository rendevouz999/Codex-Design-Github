## Asset Decisions

- Declare font style and whether commercial/free fonts are required.
- Declare image style, icon style, illustration style, and whether placeholder-only output is acceptable.
- For marketplace products, prefer editable placeholders over flattened decorative images unless the preview image is separate from source.
- For source templates, default to text clue placeholders for image zones unless the user explicitly asks for generated/final imagery.
- Standard image wording: `image placeholder: [purpose]`.
- Standard human/profile wording: `profile photo placeholder: [role]`.
- A reference image is evidence for the needed replacement slot, not permission to generate or copy an image.
- Generated images are allowed for preview, cover, mockup, or final demo assets only when that is the requested deliverable or explicitly approved.
- Missing fonts and broken image links are export-readiness blockers.
