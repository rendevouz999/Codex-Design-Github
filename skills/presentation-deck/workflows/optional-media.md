# Optional media scope

PowerPoint template design, native editing, charts/tables, placeholders, browser slides and local review are internal capabilities. User-supplied media can be embedded by the supported exporters. For native PPTX photo slots, public web, Unsplash and Pexels sourcing is authorized under [PPTX_IMAGE_SELECTION_POLICY.md](PPTX_IMAGE_SELECTION_POLICY.md). Use available built-in search, hidden in-app/isolated browsing and Firecrawl when needed. Source access, license evidence, contextual Main review, two-round takeover and precise slide assignments remain required. Optional provider API keys are not prerequisites for an available public-search route. Provider-backed image generation is conditional on the selected provider and explicit image intent.

Automated narration generation, a stock sound library and video production are not adopted template-design operations. References to those upstream extensions describe optional media, not instructions to install or call another PPT Master checkout. Use user-supplied audio when requested; do not promise automatic speech/video production. No credential or online service is required for local template creation.
